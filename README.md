# Seguridad App

Proyecto final del curso de Desarrollo Web.  
Este repositorio integra los módulos 1 al 5 y demuestra el uso de Git para control de versiones, estructura avanzada y diseño responsivo.

## 🧱 Estructura
- HTML con maquetado limpio y jerarquía clara.
- Layout con Bootstrap y Flexbox.
- CSS personalizado para adaptar la paleta de colores y estilos propios.
- Navbar responsiva y páginas adaptadas a mobile y desktop.

## 📱 Páginas adaptadas
- `index.html`
- `pages/proyectos.html`
- `pages/servicios.html`

## 🧩 Control de versiones
Incluye commits descriptivos realizados desde la consola:
- `feat: initial project setup with HTML and CSS`
- `feat: add responsive layout to proyectos page`
- `fix: adjust navbar collapse on mobile`
